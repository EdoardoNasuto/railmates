# Database Versioning

This folder is dedicated exclusively to versioning the database schema and related SQL objects (tables, functions, triggers, views, etc.).

## Purpose
- Track all changes and evolutions of the database structure over time.
- Facilitate collaboration and code reviews for database changes.
- Ensure reproducibility and easy restoration of the database state in different environments.
- Improve project transparency and maintainability.

**Note:**
This folder is not intended for direct database management or deployment scripts, but only for versioning and documentation of schema changes.
